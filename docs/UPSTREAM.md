## Framework

- [ManifestReader](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/package/manifest/reader/ManifestReader.php) defines required fields, types, nullability, allowed package types, name/version syntax, dependency list validation and duplicate/self checks.
- [Dependency](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/package/dependency/Dependency.php) accepts name, version (default `*`) and URL (default empty). Version comparisons joined with whitespace are AND, not OR.
- [PrepareInstallation](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/installer/package/PrepareInstallation.php) requires name, version, type, minimum AWT version and `main.php`.
- [Package model](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/package/model/Package.php) supplies `System`, `Plugin`, `Theme` labels for types 0/1/2.
- [InstallCommand](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/cli/commands/InstallCommand.php) requires seven positional installation arguments. It subsequently asks about admin creation and package installation; the plugin sends `n` to both. There is no invented noninteractive installer flag.
- [CLI entry](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/bootstrap/cli/handler.php) accepts argv or parsed stdin commands, supports EOF termination, and prints command results. [CLIHandler](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/cli/CLIHandler.php) specifies quote and backslash handling. The plugin uses stdin so credentials never become process arguments.
- [FrameworkInstallService](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/installer/framework/FrameworkInstallService.php) validates database type/name/user/website; defaults host to localhost and URL path to `/`; tests PDO, migrates tables, saves Website Name/Hostname Path to `awt_setting`, and writes `awt_db.php`. The plugin invokes this through the original CLI rather than copying those operations. It does not create a database.
- Installer and [DatabaseProvider](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/classes/database/provider/DatabaseProvider.php) use `mysql:host=<host>;dbname=<name>` without a separate port option. Including `;port=<port>` in the validated host parameter therefore preserves the actual PDO DSN in both places.
- [awt_config.php](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_data/config/awt_config.php) declares `DEBUG`, `REMOTE_INSTALL_FOR_DEVS`, `DEV_SECRET`. [bootstrap/dev.php](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/bootstrap/dev.php) matches POST `/dev/install`, accepts multipart `package`, `devSecret`, `action`, and responds `Installed on ...` on success.
- [bootstrap/boot.php](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/bootstrap/boot.php) loads the development endpoint only if `DEV` is defined. The published `public/index.php` never defines it. Defining `DEV` in the plugin-owned downloaded configuration is required to actually enable that existing endpoint. Existing external installations are left untouched.
- [getDomainName](https://github.com/Advanced-Web-Tools/Advanced-Web-Tools-Framework/blob/afc0a4196509f088e65ba6716503c330dc5fdaea/awt_src/functions/awt_getDomain.fun.php) appends the stored Hostname Path to the HTTP origin. The local PHP server therefore needs an explicit URL-prefix mapping for non-root site paths. The helper router does this without moving public files or rewriting the database setting.

## Template and archive layout

The [template manifest](https://github.com/Advanced-Web-Tools/TemplatePackage/blob/e9f5f6fb614fbde5052d6b9d7ec90e714ec1eb05/PackageName/manifest.json) supplies the bundled wizard defaults. The published `template.zip` has a flat package payload (`manifest.json`, `main.php`, controllers, routes, assets). It does not have the repository's `PackageName` wrapper. The framework asset has `Advanced-Web-Tools-Framework-main/` inside it despite being a published release asset. The build asset has `build/`, `build.sh`, `build.bat` at archive root.

Extraction finds a unique payload sentinel (`manifest.json`, `awt`, or `build/runtime/constants.php`) rather than assuming a wrapper name. Every entry is checked for absolute paths, `..`, Windows drives and backslash traversal before any writes. The build tool remains under its original `build/runtime` structure. Only the NAME define changes in its constants file.

## Build environment

- [README](https://github.com/Advanced-Web-Tools/Package_Build_Enviornment/blob/7f6912a65f1e8e927b2d0d40da6a8a051e5b2a1b/readme.md) documents basic Build/Deploy/fast behavior.
- [constants.php](https://github.com/Advanced-Web-Tools/Package_Build_Enviornment/blob/7f6912a65f1e8e927b2d0d40da6a8a051e5b2a1b/build/runtime/constants.php) has `define('NAME', '');`. Only that value is replaced, with PHP single-quoted-string escaping.
- [run.php](https://github.com/Advanced-Web-Tools/Package_Build_Enviornment/blob/7f6912a65f1e8e927b2d0d40da6a8a051e5b2a1b/build/runtime/run.php) is the cross-platform entry point, performs its own project-root `chdir`, reads manifest, creates ZIP and calls installPackage. The plugin invokes PHP directly rather than OS-specific wrappers.
- [env_loader.php](https://github.com/Advanced-Web-Tools/Package_Build_Enviornment/blob/7f6912a65f1e8e927b2d0d40da6a8a051e5b2a1b/build/runtime/env_loader.php) recognizes `--install`, `--fast`, `--no-install`, `--action=install|update`; the README only lists the first two. Build intentionally supplies a negative stdin answer instead of relying on the newer opt-out flag.
- [dev_env.json](https://github.com/Advanced-Web-Tools/Package_Build_Enviornment/blob/7f6912a65f1e8e927b2d0d40da6a8a051e5b2a1b/build/dev_env.json) supplies actual key casing: `release_folder`, `build_save_format`, `address`, `remote_install_path`, `devSecret`. Existing extra keys are preserved.
- [zip_creator.php](https://github.com/Advanced-Web-Tools/Package_Build_Enviornment/blob/7f6912a65f1e8e927b2d0d40da6a8a051e5b2a1b/build/runtime/zip_creator.php) defines placeholders, fast cache behavior, extension checks and ZIP contents. It overwrites its own named release archive, as the original tool intends.
- [installer.php](https://github.com/Advanced-Web-Tools/Package_Build_Enviornment/blob/7f6912a65f1e8e927b2d0d40da6a8a051e5b2a1b/build/runtime/installer.php) asks `Install package now? (y/N):` without `--install`, requires PHP cURL for deploy, joins address/endpoint, posts package/secret/action, and accepts only a successful HTTP response starting `Installed on `.

## JetBrains APIs

The plugin compiles against the actual PhpStorm 2024.1 SDK. API signatures were inspected in its bundled PHP/platform JARs. Integration uses `PhpIncludePathManager.getInstance/getIncludePath/setIncludePath`, `PhpProjectConfigurationFacade.getInterpreter`, `PhpInterpreter.isRemote/getPathToPhpExecutable/getCustomIni`, `ModuleRootManager` and `RunManager`. Password storage uses `PasswordSafe`/`CredentialAttributes`. These are direct typed calls, not reflection guesses.

The [PHP Open API documentation](https://plugins.jetbrains.com/docs/intellij/php-open-api.html) and [Gradle dependencies documentation](https://plugins.jetbrains.com/docs/intellij/tools-intellij-platform-gradle-plugin-dependencies-extension.html) were also checked. Compatibility is validated with the actual minimum SDK and Plugin Verifier; PHP library indexing is exercised in an IDE fixture rather than inferred from ordinary project content roots.
